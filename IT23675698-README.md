## Overview

Automated test suite for Chat Sinhala transliteration on https://www.pixelssuite.com/chat-translator  
Tests 50 negative test cases covering 24 Singlish input types using Playwright and Python.

## Installation

### Prerequisites
- Python 3.11 or 3.12
- Google Chrome (or Playwright will install Chromium)

### Setup
1. Navigate to project folder:
   ```cmd
   cd /d D:\test_automation
   ```

2. Install dependencies:
   ```cmd
   pip install -U pip
   pip install playwright openpyxl
   playwright install
   ```

## Running Tests

```cmd
python test_automation.py --excel "IT23675698/IT23675698_Assignment 1 - Test cases.xlsx" --url "https://www.pixelssuite.com/chat-translator" --wait-ms 5000 --type-delay-ms 80 --slow-mo-ms 200 --save-every 1 --keep-open
```

## Excel File Format

| Column | Header | Content |
|--------|--------|---------|
| A | TC ID | Neg_0001, Neg_0002, etc. |
| B | Input length type | S, M, or L |
| C | Input | Singlish text |
| D | Expected output | Sinhala text |
| E | Actual output | Auto-filled |
| F | Status | Auto-filled (Pass/Fail) |
| G | Singlish input types covered | Manual entry |
| H | Evidence or rationale | Manual entry |
